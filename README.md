# Картинки вопроса в Telegram: плагин Agents Hub

Сессия спрашивает вас, какую из картинок взять, — в Telegram приходят сами картинки. Альбомом, ответом на карточку вопроса, у каждой подпись. Под альбомом — те же кнопки, что у карточки: выбрать можно прямо там. Отметки при выборе нескольких вариантов общие с карточкой, ответили — кнопки снимаются у обеих.

Картинки плагин берёт из вопроса:

- списком в тексте вопроса, по строке на картинку: `- Синяя `/путь/к/a.png`` — подпись «Синяя» (без текста — имя файла). Тот же формат понимает плагин страницы choice-images;
- из описания варианта: путь к картинке в описании — подпись названием варианта.

В альбоме до 10 картинок, больше — несколькими альбомами. Файл больше 10 МБ или не картинка (png, jpg, webp) — строкой под альбомом.

## Поставить

«Настройки» → «Плагины» → вставить ссылку на этот репозиторий → «Проверить и поставить». Нужен хаб с Telegram, где модуль принимает факт `telegram.album`. На хабе без него плагин ничего не меняет: карточка вопроса приходит, как раньше.
